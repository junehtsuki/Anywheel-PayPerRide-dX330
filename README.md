# Anywheel Pay Per Ride — dX330 Concept Prototype

Interactive UX prototype for educational use. Standard bicycle only.

**Start:** Open `index.html` in a web browser.

**Demo flows:** Wallet, debit/credit card (mock), and PromptPay QR (mock). No real payments, GPS, or camera access. This is an independent student concept, **not an official Anywheel product**.

**For GitHub Pages:** upload the contents of this folder to the **root** of a repository. In Settings → Pages → Build and deployment, select `Deploy from a branch`, branch `main`, folder `/ (root)`.

Visual references include app-supplied promotional and interface imagery. Do not claim brand affiliation.

This is the V6 layout with one navigation-only correction: the completed ride's PromptPay payment screen can no longer navigate backward into an active ride.
